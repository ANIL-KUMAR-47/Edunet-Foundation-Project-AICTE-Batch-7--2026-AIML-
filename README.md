# Data-Driven Modeling of Salary Dynamics Using Machine Learning

## Project Description

This project is developed as part of the AICTE internship/minor project. The main aim of this project is to analyze salary data and predict salaries using machine learning techniques. The system uses real salary datasets to understand salary patterns across different job roles and experience levels.

Salary depends on several factors such as job role, experience level, company size, location, and remote work type. Traditional methods use manual analysis and simple averages which are not accurate. This project uses machine learning algorithms to provide better and more accurate salary predictions.

## Project Title

Data-Driven Modeling of Salary Dynamics Using Machine Learning

## Project Objectives

- To analyze salary data using machine learning techniques
- To understand salary trends across different job roles
- To build a salary prediction system
- To compare different regression algorithms
- To improve prediction accuracy

## Algorithms Used

The following regression algorithms are used:

- Linear Regression
- KNN Regressor
- HistGradientBoosting Regressor

These algorithms are used to predict salary values and compare their performance.

## How to Run the Project

Step 1: Install Python and required libraries.

Step 2: Open the project folder in Jupyter Notebook or VS Code.

Step 3: Run the file:

Salary_Insights_by_Job_Role_(2024).ipynb

Step 4: The system will analyze the dataset and generate salary predictions.

## Results

The system analyzes salary patterns and predicts salaries using machine learning algorithms. The HistGradientBoosting Regressor model produced better prediction accuracy compared to other models.
